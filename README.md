# Astros Group Outings — concept prototype (GSCG)

A demo group-sales page for the Houston Astros with one tab per community (Church Groups, Hispanic Community, Youth Sports, Schools, Nonprofits). Built by the Gonzaga Sport Consulting Group to present at the midpoint/final. Not an official Astros page; the form does not send or store data.

Live: https://mateosandoval10.github.io/gscg-astros-groups/

- All copy lives in `content.js` (one entry per community).
- "Strategy notes" toggle (top bar) reveals GSCG's value proposition, sample outreach message and channels for each tab.
- Photos: Wikimedia Commons (CC BY / CC BY-SA / CC0); Astros logo via Wikimedia Commons.
